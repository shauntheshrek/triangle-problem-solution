## Overview

A simple web application that classifies a triangle based on the lengths of its
three sides. The application identifies valid triangles as Equilateral,
Isosceles, or Scalene and handles invalid inputs and triangle dimensions.

## Features

- Classifies valid triangles as equilateral, isosceles, or scalene.
- Validates that all three side lengths are provided.
- Accepts positive whole-number inputs.
- Checks the triangle inequality theorem to identify invalid triangles.
- Displays appropriate messages for invalid inputs and triangle dimensions.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Enter the three side lengths.
4. Click **Classify Triangle** to view the result.
